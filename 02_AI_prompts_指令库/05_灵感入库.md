# 05 灵感入库

**什么时候用：** 看书划线了、刷到好文章了、听人说了句戳心的话
**要花多久：** 30 秒（贴完就走）

---

## 你只需要说一句话

```
灵感入库：【把书摘 / 文章 / 截图文字 / 别人的话 贴在这里】
```

就这样。**不用打开这个文件，不用复制，不用改字。**

想说明出处就顺手加上，不加我也能干活：

```
灵感入库：《被讨厌的勇气》第 3 章
人的烦恼，皆源于人际关系。
```

## 我会做什么

| 步骤 | 我干什么 | 你要做的 |
|---|---|---|
| 1 | 按模板存一张灵感卡，放 `06_sources_原始资料/`，原文一字不改 | 不用管 |
| 2 | 填"它到底在说什么"——一句话，客观复述作者意思，不带评价 | 不用管 |
| 3 | 指出哪些是作者的观点、哪些能长成你自己的看法 | **看一眼**，这句是你的 |
| 4 | 结合你的档案，给 3 个"现在就能用"的动作 | 挑一个顺手的试 |
| 5 | 问你要不要把某个概念单独做成知识卡 | **说"要"或"不要"** |

**你全程只做两件事：看一眼第 3 步，答一句第 5 步。**

---

## 为什么要区分"别人的"和"我的"

这是知识库里最重要的一条分界线。

- **作者的观点** → 存着，是资料
- **我的看法** → 才是知识卡，是你的东西

大部分人做了十年笔记，存的全是别人的观点，所以十年后还是"好像看过但想不起来"。

**灵感卡里那句话，一定要有你自己的半句。**

---

## 为什么明说"想不出就别硬凑"

因为大部分书摘，**根本就没有 3 个能落地的动作**。

一句好的话，可能只是让你换个角度看事情，它不长出任何"步骤"。这很正常。

但如果口头要求"给我 3 个方法"，AI 就会硬凑——凑出来的都是"保持学习心态""多与人交流"这类正确的废话。这种东西写在库里，三个月后你翻到只会觉得烦。

**宁可 0 条动作，也不要 3 条废话。**

你的精力贵，别用假动作把它填满。

---

## 一个小技巧

看完一本书不用整本摘。只抓**让你停下来愣了三秒**的那几句。

一本 300 页的书，能留下 5 句话就是赚了。

那 5 句话，每句配你自己的半句感想，就是 5 张卡的种子。

## 执行细则（给我看的，你不用读）

收到 `灵感入库：` 触发词后，按顺序做：

1. 先读 `00_给AI的说明书.md` 和库根目录 `00_我的档案.md`，读完再动手。
2. 用 `07_Templates_模板/灵感卡模板.md` 存卡，放 `06_sources_原始资料/`。
   - 文件名用内容主题，**不要用日期**。
   - **原文部分一字不改，原样保留。** 我贴的错别字也不改。
   - "它到底在说什么"这一栏由你填：一句话，客观复述，不带评价。
3. 告诉我：这段里哪些是"作者的观点"，哪些可以长成"我自己的看法"。分两栏列，别混在一起。
4. 结合 `00_我的档案.md`，给 3 个"现在就能用"的动作。每条标明**适用场景 / 具体步骤 / 我能用它做什么**。
   **想不出就说想不出，不要硬凑。** 宁可 0 条，不要凑数。
5. 最后问我一句：这里面有没有值得单独成卡的概念？有就列出来，等我确认，别自己写。
6. 我确认要成卡之后，才建知识卡，并更新 `08_Maps_导航/00_首页.md` 和 `操作日志.md`。
7. 干完给我清单：新建了什么、改了什么。
