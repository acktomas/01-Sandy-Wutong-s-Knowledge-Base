# PID 电机角度控制

## 一句话目标
> 旋钮转到哪，电机就跟到哪，误差 ±3° 以内，不来回抖。（课堂演示档次；±1° 是理论余量，不作为本次验收标准）

## 为什么要做
> 舵机只能到 180°，机械臂做不了全角度；而且 PID 是创客课最该讲、也最难讲的一课，自己先蹚通才能教给学生。

### 换算（2026-11-02 修正）

```
每圈脉冲数 = 11（A 相每圈脉冲）× 30（减速比） = 330    ← 单相计数
角度      = 脉冲数 ÷ 330 × 360°
分辨率    = 360 ÷ 330 ≈ 1.09°/脉冲
```

**一个脉冲约 1.09°，给学生的说法就是"一个脉冲差不多 1 度"。**

口径要分清：
- **单相计数**（只数 A 相上升沿）= 330 —— **代码用的是这个**
- 双相计数（A、B 都数）= 660
- 四倍频 = 1320

> **更正记录（2026-11-02）**：早期按 660 写，是把"AB 双相"误当成了计数方式。
> 实际代码只在 A 相上升沿触发，B 相仅用于判方向，所以是 330。
> 依据：编码器资料的线序图——"黄 C1/A 每圈 11 个脉冲"，11 × 30 = 330。

### 三个已做的决定

| 决定 | 选了 | 放弃了什么 |
|---|---|---|
| 驱动板 | L298N | A4988 是步进专用，接直流电机不会转 |
| 电源 | 12V 1.5A 单路 | 堵转 2.4A 会超，所以 PWM 限 70%、不许堵转 |
| 编程语言 | MicroPython | 放弃了性能（学生会这门语言是硬约束） |

## 分几步

> 一次只做一步，每步控制在 20 分钟内。**不要一次把 PID 调完，这是这个项目最容易死的地方。**

- [ ] **1. 只读角度，不控制**：手转输出轴整整一圈，串口打印脉冲数，核对是不是 330
- [ ] **2. 开环摸底**：PWM 固定值让电机转，每 100ms 打印一次角度；同时找出**最小启动 PWM**（低于它电机不动）
- [ ] **3. 只上 P**：调 Kp 到能转到目标角，允许有超调和抖动
- [ ] **4. 加 D**：把超调压下去，让角度稳稳停住
- [ ] **5. 加 I**：消掉最后那点静差，误差进 ±1°，记录一组目标角 ↔ 实际角数据

## 整定口诀（一次只动一个数）

| 看到什么 | 改哪个 | 怎么改 |
|---|---|---|
| 爬到一半不动了 | Kp | ×2 |
| 冲过头再弹回来 | Kp↓ 或 Kd↑ | ÷2 / ×2 |
| 到位后来回摆不停 | Kd | ×2 |
| 停住但差几度 | Ki | 0.05 起 |
| 电机嗡嗡抖、不过去 | Kp 或 Kd 太大 | 都 ÷2 |
| **一开机就往一个方向猛冲到底** | **编码器方向反了** | **中断里 `+1`/`-1` 对调** |
| 完全不动、`count` 一直是 0 | 编码器没接上 | 查 3V3 和 A 相 |

顺序：**Kp 先给 5，只看它能不能转到位 → 加 Kd 压超调 → 最后 Ki 消静差。**
Ki 那步在课堂演示档次上可以不做。
