# 接线与自检

> 目标档次：**课堂教学用**（误差 ±3° 即可，现象明显优先）。
> 保留这一句：没有它，三个月后看到"±1°"会以为当初要求这么高。

## 一、设备清单

| 用途 | 设备 |
|---|---|
| 主控 | ESP32-S3-DevKitC-1（USB 供电） |
| 驱动 | L298N（12V 供电） |
| 电机 | JGB37-520-12100-EN，减速比 30，编码器 11 PPR |
| 旋钮 | 10k 电位器 |
| 电源 | 12V 1.5A（只给 L298N） |
| 其他 | 杜邦线、面包板（只走信号线）、USB 线 |

**明确不用**：A4988（步进驱动，直流电机用不了）、20k 电位器。

## 二、接线图（共 16 根，照着接）

> 左边是这头，箭头右边是那头。★ 是要注意的地方。

```
【12V 电源 → L298N】(先别插插座)
+12V    →  L298N  +12V      螺丝端子拧紧
GND     →  L298N  GND       螺丝端子拧紧

【共地】★ 最容易漏，漏了整台机不动
L298N GND     →  ESP32  GND
编码器 GND    →  ESP32  GND
电位器 左脚   →  ESP32  GND

【电机 2 根 · 粗线】
红线    →  L298N  OUT1      ★ 红白对调 = 反转，不会烧
白线    →  L298N  OUT2      ★ 走螺丝端子，别插面包板

【L298N → ESP32 控制 3 根】
ENA     →  ESP32  GPIO4      ★ 板上跳线帽必须拔掉
IN1     →  ESP32  GPIO5
IN2     →  ESP32  GPIO6

【编码器 4 根细线 · PH2.0 头】
蓝线    →  ESP32  3V3        ★ 编码器电源正，是蓝不是红
黑线    →  ESP32  GND        ★ 编码器电源负
黄线    →  ESP32  GPIO7      ★ A 相，电机轴每圈 11 个脉冲
绿线    →  ESP32  GPIO8      ★ B 相，只用来判方向

【电位器 3 根】
左脚    →  ESP32  GND
中间    →  ESP32  GPIO1      ★ 只有这根是信号
右脚    →  ESP32  3V3        ★ 3.3V，别接 5V

【ESP32 供电】
USB     →  电脑             ★ 不跟 12V 混用
```

**引脚占用一共 6 个**：`GPIO1` 电位器、`GPIO4/5/6` 控制、`GPIO7/8` 编码器，全是普通 IO，互不冲突。
`3V3` 供两处（编码器 VCC、电位器右脚）；`GND` 供四处（L298N、编码器、电位器、12V 负极）。

> 更正记录：早期版本把编码器 A/B 写成 GPIO4/5，那是错的——GPIO4 已给 ENA，会撞车。

## 三、L298N 板上三件事

| 位置 | 怎么做 | 为什么 |
|---|---|---|
| `ENA` 跳线帽 | **拔掉** | 不拔只能全速，PWM 失效 |
| `5V_EN` 跳线 | 保留短接 | 12V 供电时给内部逻辑供电 |
| `+5V` 端子 | 什么都不接 | 它是输出，接 ESP32 会冲突 |

## 四、动手顺序

1. 12V 不插插座，USB 不插电脑
2. 先接**共地那三根**（L298N、编码器、电位器的地都接到 ESP32 的 GND）
3. 再接 12V 到 L298N 的两根
4. 再接电机两根，螺丝拧紧拽一下
5. 再接编码器其余三根（最细，容易错，一根一根来）
6. 再接电位器其余两根
7. 最后接控制三根
8. 全部接完拍照，再插 USB，最后插 12V

**先接地再上电的理由**：地是公共参考。没有它，PWM 信号没有基准，电机可能乱转或驱动板发热。

## 五、上电前 5 项检查

1. 编码器的**蓝线**接的是 3V3？（红白是电机线，别接到 ESP32 上）
2. 电位器两端是 3V3 和 GND，不是 5V？
3. L298N 的 GND 和 ESP32 的 GND 通了？（万用表通断档最稳）
4. ENA 跳线帽拔了？
5. 电机线在 OUT1/OUT2 螺丝端子上，没插面包板？

## 六、故障对照

| 现象 | 多半是 |
|---|---|
| 电机完全不转，板子没反应 | 共地那根没接 |
| 只全速转，调不了速 | ENA 跳线帽没拔 |
| `count` 一直是 0 | 编码器 VCC 或 A 相没接好，或供电不是 3V3 |
| 电机猛冲到底不停 | 编码器 A/B 接反，或代码里 `+1/-1` 要对调 |
| 旋钮拧到底电机还乱跑 | `RAW_MIN/RAW_MAX` 没按实测填 |
| 一启动 ESP32 就重启 | 电机和主控共用电源，或地线没接好 |

## 八、已知取舍

| 取舍 | 决定 | 理由 |
|---|---|---|
| 绝对零点 | 不做，用相对角度 | 课堂演示够用，省掉限位开关；代价是不能重复定位 |
| 电源 | 12V 1.5A 够用 | 空载 0.15A；但堵转 2.4A 会超，所以限占空比 70% |
| 编程语言 | MicroPython | 学生会这门语言，这是硬约束，优先于性能 |
| PID 采样周期 | 20ms | 太短 MicroPython 跑不动，太长控制迟钝 |
