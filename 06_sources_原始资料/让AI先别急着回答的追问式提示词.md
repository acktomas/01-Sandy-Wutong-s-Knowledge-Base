# 让 AI 先别急着回答的追问式提示词

## 原文 / 原话

```
当一个问题比较复杂，为了让AI更好帮我解决问题，可以参考下面的提示词：请先不要回答我的问题。在给出答案时，请先完成以下分析：1、指出我在这个问题中没有明确表述、但已经默认成立的假设；2、告诉我还缺少哪些关键信息，以及这些信息可能如何改变你的答案； 3、指出人们在处理此类问题时最常犯的一个错误。然后，请向我提出一个最关键的问题。这个问题应该能够帮助你理解我的真实目标和具体情况，让最终答案真正对我有用，而不是一组随意套用的通用建议。等我回答以后，你再给出最终输出。我的问题是：[粘贴你的问题]”
```

## 它到底在说什么

> 别让 AI 一次答完。先让它做四件事——挖出我没说出口的假设、点明缺哪些关键信息、指出这类问题的常见错误、反问我一个最关键的问题——等我答完那一问，再输出答案。
