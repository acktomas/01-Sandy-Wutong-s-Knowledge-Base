   - `整理日记` / `整理：日期` → 01
   - `体检` → 02
   - `出稿：方向` → 03
   - `问库：问题` → 04
   - `灵感入库：原文` → 05
   - `档案更新：变了什么` → 06
   - 均在 frontmatter 加 `触发词:` 字段。
3. **`00_我的档案.md` 对应的 user MEMORY.md 新增「知识库触发词」节**，含文件映射表 + 铁律"以后设计任何新流程都不许要求用户复制粘贴长文本"。作用：新会话自动加载，用户不必再说"读说明书"。

## 新增第 7 个口令：`别急着答：`

**来源：** 用户灵感入库了一段"先别答题、先做四步分析再反问"的提示词（已存 `06_sources_原始资料/让AI先别急着回答的追问式提示词.md`）。我建议把它固化成触发词 `追问：`。

**命名争议（值得记）：** 用户觉得"提问/追问"不通俗，提议用「**预设提问**」。

**我否掉了，理由：** "预设"在中文里已有固定语义——事先设置好的东西（打印机预设、手机预设）。"预设提问"会让人以为是"提前写好的一组问题模板"，而实际动作是"你先别答，先反问我一句"。**词和动作错位，比原词更难懂。** 并给出一条判断触发词的标准：**说出来像不像人话。**

用户最终选了「**别急着答：**」——比我推荐的"先问我"更有语气，符合他平时说话的样子。**这个选择本身印证了触发词该由用户自己定，因为语感是他自己的。**

**已落地：**
- 新建 `02_AI_prompts_指令库/07_别急着答.md`（含"什么时候别用它"的边界、约 300 字篇幅纪律）
- `00_给AI的说明书.md` 触发表加一行
- user MEMORY.md 触发表加一行
- `00_使用手册.html` 05 速查：六个词 → 七个词，新增卡片
- `00_从这里开始.md`「六个词」改为「几个词」（不再写死数量，避免每次加口令都要改）

**关键定制点：** 该口令第 5 步"只反问一个最关键的问题"必须**带 2-4 个选项让用户点选**，不许开放式填空。依据是 user MEMORY 里的硬规则"需要决策时给选项，不让其填空"。

**洞二：首页只有知识卡索引，没有原始资料的入口。**
灵感卡存进去后在首页无处可点，等于沉底。已在"知识卡索引"之后新增「## 资料索引」一节，收录灵感卡，同样由 AI 维护。

**沉淀的判断：知识库的检索路径必须跟存储位置一一对应。** 每新增一类存放位置，就要回头检查口令的检索范围有没有覆盖它——否则"存了"和"能找回来"是两件事。
